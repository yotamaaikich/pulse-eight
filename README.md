# PIANO PULSE

ボカロ・まどマギ・osu!定番・太鼓の達人収録曲の35曲を、白鍵8つで演奏するブラウザ音ゲー。
※現在ある譜面の創作にはcodexが使われています。

**プレイ： https://yotamaaikich.github.io/pulse-eight/**

## 操作

| キー | 操作 |
| --- | --- |
| A S D F / J K L ; | 白鍵8つ（左から順） |
| ↑ ↓ | 選曲 |
| ← → | EASY / NORMAL / HARD |
| Enter | 開始・再開・リトライ |
| Esc | 一時停止、停止中・結果画面から選曲へ |
| Shift+R | リトライ（HARDのプレイ中はRがFLOAT用） |
| V | 譜面と鍵盤だけを全画面表示 / 解除 |
| Shift+O | 設定（HARDのプレイ中はOがFLOAT用） |
| Space | HARDFLOAT。押したままレーンキーを移動できます |
| S（結果画面） | スコア登録 |

設定・選曲・名前変更などはTabで移動し、Enterで操作できます。キー配置は設定画面で変更できます。

## ゲーム

- 奥から手前に迫る8レーン。レーン、ノーツ、長押しの帯は同じ遠近投影を使用。ノーツとピアノ鍵盤の文字ラベルは省略。白いレーン補助線と中央の境界線、左手・右手の表示で操作範囲を区別します。同時押しも通常と同じ左右の色で、白い横線で結びます。
- 単押し・長押し・同時押しに対応。NORMAL・HARDは音の強いアタックを2鍵の同時押しで強調します。長押しは終端まで保持し、早く離すとMISS。長押し中の別キー入力にも対応します。
- HARD限定FLOATはレーンキーを押したまま220ms以内にSpaceを押します。FLOAT区間の直前からSpaceを押し、帯が終わったら離します。区間外の押しっぱなしはコンボ切断になります。黄緑色の上向きFLOAT矢印で表示し、連続するFLOATノーツを黄緑色の帯でつなぎます。帯に沿ってSpaceを押したままレーンを移動できます。Spaceだけでは取れず、通常の長押しはSpaceを離しても継続します。EASY・NORMALにはFLOATは出現しません。上段8キーの操作は撤去しました。
- Escで一時停止したまま選曲・難易度変更ができます。左右の選択ボタン、矢印キー、または一時停止画面の「曲・難易度を変更」を使用します。「今のプレイがリセットされます」の確認で確定するとスコア・コンボ・進行時間をリセットします。キャンセルではそのまま再開できます。全画面でも変更ダイアログを使用できます。
- 全画面は譜面エリアだけを表示し、スコア・現在のコンボ・達成率も譜面内に表示します。右上の戻るボタンまたはVで解除できます。
- 白鍵は手動、黒鍵は装飾。黒鍵には文字ラベルを表示せず、得点にも含めません。
- 全曲フル尺（2:01〜5:50）。公式YouTubeプレイヤーの再生位置と同期し、バッファリング・一時停止中は譜面も止まります。
- 判定：PERFECT ±45ms / GREAT ±90ms / GOOD ±140ms / BAD ±170ms。
- スコアは100万点満点。端末の自己ベストと、曲・難易度・譜面バージョンごとの世界TOP10。
- ノーツ速度、動画音量、ピアノ音ON/OFF・音量、判定オフセット、キー配置を端末に保存。動画は初期50%、ピアノ音は初期18%。ピアノ音は試験曲「モニタリング」のみで、読み込み・一時停止中には鳴りません。

## 音声と譜面

曲の音声はYouTubeの公式動画です。「モニタリング」1曲に限り、ノーツを押す瞬間に短い実録ピアノ音を重ねる試験機能を追加しました。音程は設定から読み込むMML／音程JSONファイルの音高・時刻・音価から割り当てます。同じレーンでもメロディの進行で音程が変わり、同時押しには譜面内の別声部を使います。和音の機械的なループや、休符への適当な音の補完は行いません。音程データはこのブラウザのlocalStorageだけに保存し、公開サイトやサーバーには送信・同梱しません。

設定でON/OFF・専用音量（初期18%）・試し弾きを利用できます。動画音量とは独立しています。単押しは短く減衰し、長押しは頭で1回だけ鳴らして自然に減衰、同時押しは全体のゲインとコンプレッサーで音量を抑えます。FLOAT成功時は別の短いきらめき音です。AudioContextはプレイ開始の操作で準備し、キー解放・長押し途中のコンボ加算・一時停止からのキー復帰では音を鳴らし直しません。他の曲とチュートリアルは従来どおりピアノ音なしです。ピアノ単音はAlexander Holm氏のSalamander Grand Piano（CC BY 3.0）を同梱しています。実行時は同じサイトから読み込み、打鍵直前の無音を除き、短いリリースで再生します。クレジットは `audio/piano/CREDITS.txt`。プレイ時の原曲はYouTubeで再生します。解析用に取得した音声や字幕本文は配信ファイルへ同梱しません。

譜面作成・「みんなの譜面」の画面は撤去済みです。既存のサーバーデータは削除せず保持しています。

## ローカル起動

Node.jsがあれば、追加パッケージは不要です。

```sh
node dev.mjs
```

表示されたローカルURLをブラウザで開きます。動画とオンラインランキングにはインターネット接続が必要です。

## 構成

ビルド不要のHTML / CSS / JavaScript。GitHub Pagesは`main`ブランチのルートを配信します。`engine.mjs`はブラウザとサーバーで共有する譜面・判定処理、`geometry.mjs`はレーンとノーツで共有する遠近投影です。`npm test`で判定・長押し・同時押し・投影・再生待機・カスタム譜面を検証できます。

オンライン機能はSupabase Edge Function `pulse-keys`と専用テーブルで保存します。初期構造は`cloud/schema.sql`、譜面公開の追加構造は`cloud/community.sql`です。`pulse_keys_charts`は公開譜面、`pulse_keys_chart_scores`は譜面ごとの記録、`pulse_keys_runs`は所有者付きプレイ情報、`pulse_keys_scores`は標準譜面の記録です。Edge Functionは`cloud/index.ts`をエントリーポイントとし、同じ配置の`cloud/service.mjs`とルートの`engine.mjs`・`expansion.mjs`・`taiko.mjs`・`proseka.mjs`を含めてデプロイします。長曲のコンボ上限拡張は`cloud/expanded-tracks.sql`です。

ブラウザに置くのは公開用キーだけです。テーブルはRLS有効、`anon` / `authenticated`に直接の読み書き権限はありません。公開APIが名前・スコアなどの表示項目のみ返します。端末ごとのランダムなトークンでプレイの所有を確認し、サーバーで入力履歴からスコアを再計算します。開始回数制限、完走時間確認、二重登録防止、自己ベストの原子的更新を行います。

これはコミュニティ向けランキングです。ブラウザの入力履歴を完全に不正耐性のあるものにはできず、競技大会用のアンチチートではありません。端末の保存領域を消すとプレイヤーID・設定・端末の自己ベストを失います。公開済みのスコアは残ります。

音楽はYouTubeの公式動画を埋め込んで再生するため、再生前・再生中にYouTubeの広告が入る場合があります。ゲームの開始画面と譜面の全画面内にも案内を表示します。

読み込み・バッファリング・本編の再生時間が止まっている間は、音量を0%にして「動画読み込み中」と表示し、譜面と判定も停止します。本編の再生時間が進むことを確認してから設定音量に戻します。待機しても音量設定そのものは書き換えません。広告が長くても18秒で強制停止せず、再生を待ちます。

[YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)には広告の検出・スキップを行う公開APIがなく、ゲーム側で「5秒後に自動スキップ」は実装していません。再生時間の進行を使った待機判定なので、広告中も本編と同じように時間が進む場合など、判別できない広告があります。全種類の広告の消音を保証するものではありません。必要な場合はVで全画面を解除して、YouTubeプレイヤー内のスキップや音量を操作できます。プレイヤーのシーク・再生速度変更を検出した回はランキング対象外です。

## 操作チュートリアル

タイトル下またはヘッダーの「チュートリアル」または遊び方から起動できます。単押し・長押し・同時押し・FLOAT・Spaceを押したままの帯に沿ったレーン移動を、実際の判定エンジンで順番に練習します。キー変更に対応し、失敗時は自動再挑戦。動画の読み込みやスコア送信は行いません。

難易度別の練習：EASYは単押し・長押し、NORMALは同時押しまで、HARDはSpaceFLOATとレーン移動まで。HARDでもFLOAT練習をオフにできます。難易度を切り替えると練習を最初からやり直します。

動画の準備完了後は3秒のカウントダウンを表示し、その間は動画・譜面・判定を停止します。途中の読み込み待ちや一時停止からの再開にも準備時間を入れます。

## 長押しとFLOATのコンボルール

長押しは保持中0.25秒ごとにコンボを加算します（スコア・判定数は従来のノーツ単位）。FLOATは1.2秒以内で続く矢印を帯でつなぎ、区間の前220ms・後390msを含めSpaceを受け付けます。区間外でSpaceを押す／押し続けるとコンボが切れ、一度離すまでFLOAT判定は無効です。入力履歴にSpaceの押下・解放を保存し、サーバーでも同じルールで再判定します。譜面改訂のためランキングはpiano8-vocal-v8に分離し、旧記録は保持します。

難易度のLVは手動の合計ノーツ数から `max(1, ceil(ノーツ数 / 100))` で決定します。長押し・FLOATは各1個、同時押しはキーごとに数え、黒鍵補助と保持中のコンボ加算は除きます。選曲欄の並べ替えは選択中の難易度を使い、LVが同じ場合もノーツ数順、同数なら収録順です。上下キーの選曲も表示順に従います。

HARDのFLOAT配置は、元のリズム位置を使った最大3矢印・約2.4秒以内の短いフレーズです。フレーズ間は最終矢印から次の開始まで6秒以上空け、冒頭8秒・末尾約4秒はFLOATを置きません。全35曲を自動検証し、帯の連結とSpace受付は同じ境界を使います。

カウントダウンは巻き戻し位置と一時停止が150ms以上安定した後に開始します。3秒後はPLAYINGを確認した最初のフレームから音声と判定を再開し、再度の無音の進行確認は行いません。巻き戻し直後の一時的なPAUSED／BUFFERING（400ms未満）は時刻を凍結して扱い、再カウントを起こしません。実際に停止が続く場合は従来どおり待機・カウントで復帰します。
