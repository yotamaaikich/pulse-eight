# PIANO PULSE

## 遊び方

[ブラウザで遊ぶ](https://yotamaaikich.github.io/pulse-eight/) · [Windows版をダウンロード](https://github.com/yotamaaikich/pulse-eight/releases/latest)

35曲を8キーで演奏するリズムゲームです。譜面は曲に合わせた独自アレンジです。

| 操作 | キー・タッチ |
| --- | --- |
| 左4レーン / 右4レーン | A S D F / J K L ;（設定で変更可能） |
| 単押し・同時押し | ノーツが判定ラインに重なる瞬間に押す |
| 長押し | 帯の終わりまで押し続ける。途中もコンボ加算 |
| FLOAT（HARD限定） | 指定のレーンを押しながらSpace。帯に沿ってキーを移動し、区間の終わりでSpaceを離す |
| タッチ | 画面の8鍵をタップ・長押し。複数の指・スライドに対応 |
| タッチのFLOAT | 画面下の小さいペダルを押さえながら、別の指で鍵盤を操作。帯の終わりでペダルを離す |
| 選曲 / 難易度 | ↑ ↓ / ← → |
| 開始・再開 | Enter |
| 一時停止・選曲へ | Esc |
| リトライ / 設定 / 譜面全画面 | Shift+R / Shift+O / V |

FLOAT区間外でSpace・ペダルを押し続けるとコンボが切れます。EASY・NORMALにはFLOATがありません。上の「チュートリアル」で難易度別に練習できます。

設定で動画音量、ピアノ音、ノーツ速度、判定タイミングを調整できます。タッチ用ペダルはHARDのみ表示し、設定で表示を切り替えられます。レベルは100ノーツごとに+2です。

ログインせずゲストで遊べます。プレイヤー画面のGoogleログインで、ブラウザ版・Windows版の登録済み自己ベストを共有できます。ゲストの記録は端末ごとに保存し、自動でアカウントへ移しません。1曲完走したら「ランキングに登録」で名前と結果を公開できます。

音楽はYouTubeの公式動画で再生します。インターネット接続が必要で、広告が入る場合があります。本編の準備ができたら3秒のカウントで開始します。動画のシーク・速度変更をしたプレイはランキング対象外です。

Windows版はインストーラーまたはZIPから起動できます。Discordのデスクトップ版を起動すると、曲名・難易度・プレイ状況を表示します。アプリ設定から無効にできます。
