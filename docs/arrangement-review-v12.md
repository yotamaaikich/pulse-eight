# 35曲・105譜面の区間別アレンジ v12

35曲すべてのフル音源を解析し、曲内の区間ごとに密度・同時押しの頻度・長押しの間隔・左右の受け渡しを調整しました。v11の実音アタック時刻を保持し、一定間隔のノーツや共通フレーズを追加する処理はありません。

公開譜面はSekai ViewerのMASTER表示を参照しました。短縮音源とフル版を6秒窓の波形相関で照合し、0.90以上の一致が連続する区間だけを使用。編集で飛ぶ箇所は別区間として扱い、対応しない中間部へ時刻を引き伸ばしていません。参考情報は8秒ごとの密度・同時押し比率・ロングの占有度の集計に限り、元譜面のノーツ時刻列・レーン配置・画像・音源は同梱していません。8キーのノーツ時刻と配置は本ゲームのフル音源解析から独自に選択しています。

参考譜面の傾向を反映した区間がある曲は14曲です。残り21曲、および一致しない区間は、各曲のフル音源の実音アタック・音量・音色変化・歌の区切りを使った独自アレンジです。メズマライザー・初音ミクの消失・腐れ外道とチョコレゐトは比較音源との対応を十分な確度で確認できず、ÅMARAは比較音源を取得できなかったため、参考譜面の傾向は反映していません。全35曲を既存ゲームから変換したという意味ではありません。

追加のロング候補は同じ実音アタックから始まり、音高クラスと音量が持続する区間に限定。測定した候補を全て配置するのではなく、既存ロングと間隔・占有を考慮して選びます。ノーツの音程推定・ピアノ音色・YouTubeの同期処理は今回変更していません。

検査は全105譜面の満点入力再生、保持レーンの衝突、同時押しの形、FLOATの区切り、譜面配置図の目視です。音を聴きながら全35曲を通し演奏した検査ではありません。細かな耳合わせまで完了したとはしていません。
