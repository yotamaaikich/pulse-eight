アプリを開く前に最新版の有無を確認するWindows版です。

- 新しい安定版があれば「最新版があります」と表示
- 公式ダウンロードページを開くか、そのまま起動するか選択可能
- 通信待ちは最大3秒。オフラインやAPI制限時も起動可能
- 認証から戻るときは更新確認を省略し、ログイン完了を優先

118件のテスト、保護設定を有効にしたEXEの起動、OS暗号化の検証を通った配布ファイルです。

PIANO-PULSE-Setup-1.6.1.exe はインストーラー、PIANO-PULSE-1.6.1-x64.zip は展開して「PIANO PULSE.exe」を起動します。正式なWindowsの発行元署名は未設定です。GitHubの来歴証明とSHA-256を添付しています。
