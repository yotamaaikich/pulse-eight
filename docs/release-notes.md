開始直後の停止を減らしたWindows版です。

- 一覧のレベル表示のために35曲分の譜面を一度に生成する処理を廃止
- 選択中の譜面・ピアノ音程を画面とは別のWorkerで事前準備。初回スタート中も画面を止めません
- 譜面の準備中は判定を止め、曲変更後に古い譜面が戻ってくる場合も破棄
- MVの先読みを確認してからカウントイン。先読み情報が古い場合は待ち続けません

101件の自動テスト、Windowsビルド、生成EXEの起動チェックを通った配布ファイルです。譜面の内容・判定・音程は変更していません。

PIANO-PULSE-Setup-1.5.4.exe はインストーラー、PIANO-PULSE-1.5.4-x64.zip は展開して「PIANO PULSE.exe」を起動します。

音楽・動画・オンライン機能にはインターネットが必要です。YouTube公式動画のため広告が入る場合があります。コード署名証明書は未設定です。
