PIANO PULSEをWindows x64のアプリとして遊べます。

- `PIANO-PULSE-Setup-1.5.3.exe`：インストーラー
- `PIANO-PULSE-1.5.3-x64.zip`：展開して「PIANO PULSE.exe」を起動
- 8キー、タッチの同時押し・長押し、小型FLOATペダルに対応
- Discordに曲名・難易度・プレイ状況を表示。アプリ設定でOFFにできます
- Googleログインでブラウザ版・アプリ版の登録済み自己ベストを共有。ゲストでも全曲プレイできます

WindowsアプリのYouTubeエラー153を修正しました。実機で動画と譜面の進行、ブラウザ・アプリ双方のGoogleログイン、Discordプロフィールのゲーム表示を確認しています。認証後の一時URLを動画へ渡さないよう、動画の読み込み順も調整しました。

96件の自動テスト、Windowsビルド、生成EXEの起動チェックを通った配布ファイルです。SHA-256は`SHA256SUMS.txt`を参照してください。音楽・動画・オンライン機能にはインターネットが必要です。YouTubeの公式動画を使うため広告が入る場合があります。コード署名証明書は未設定です。
