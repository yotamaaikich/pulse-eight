# トリルの8レーン分散 v18

操作キーは `A S D F / J K L ;` の固定です。初音ミクの消失、初音ミクの激唱、マシンガンポエムドール、ヤミナベ!!!!、What's up? Pop!、テトリス、メズマライザーのNORMAL・HARDで、トリルの位置を8レーン全体に分散しました。7曲・14譜面すべてでトリルに全8鍵を使います。

以前の配置選択は最初に見つかった空き位置を採用していたため、中央や同じ数鍵へ偏っていました。今回は全候補位置を比較し、各レーンの使用数と未使用レーンを考慮して選択します。全区間の配置後にもう一度評価し、後半の区間で端の鍵を使えない場合も見直します。

## 検証

- 全35曲・105譜面の95,730ノーツをv17と比較。変わったのは517個のトリルのレーン位置です。
- トリルは従来と同じ80区間。4打ごとの交互打ち、境界で同じ鍵が続かないこと、移動幅、上昇・下降、保持中の鍵との重複回避を検査しています。
- 全105譜面でレーン位置以外のノーツ情報が一致し、ピアノの音程も一致することを検査しました。タイミング・ロング・同時押し・FLOATは維持しています。
- `npm test`: 84件成功。7曲それぞれのNORMAL・HARDが全8レーンを使う回帰検査を追加しました。
- 配置データと入力再生による検証です。聴きながらの通し演奏による検証ではありません。

ブラウザとオンライン採点を `piano8-trills-v18` に揃えています。過去のスコアは削除せず、譜面バージョンごとに保存します。
