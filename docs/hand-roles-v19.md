# 全35曲の主旋律と伴奏 v19

全35曲・EASY/NORMAL/HARDの105譜面を更新しました。操作キーは `A S D F / J K L ;` の固定です。

主旋律はフレーズ内を左右どちらかの4鍵で追います。反対の手はアクセントと長押しを中心にした単純な伴奏を取り、フレーズの区切りで左右の役割を交代します。区切りには元データの歌の境界、休符、数小節ぶんの長さを使います。伴奏は隣接する鍵を中心にゆっくり動き、保持中の鍵は避けます。

以前の速いメロディを1音ごとに左右へ振る配置を改めました。全105譜面のフレーズ内の主旋律73,533組を比較すると、左右の切り替わりは44,070組から0組になっています。主旋律の担当交代はフレーズ間にあります。

## トリル

添付画像の通常トリル、移動トリル、片手トリルと反対の手のロングが見えるよう、伴奏の同時押しでは主旋律の交互打ちを分断しない処理へ変更しました。

- 最初の8打は同じ2鍵の交互打ちです。途中に無関係な主旋律ノーツを挟みません。
- HARDは12〜24打の区間を優先。曲のリズムに長い連続区間がなければ8打の区間を使います。
- 移動トリルは最初の8打の後、音の輪郭に合わせて4打ごとに1レーン以内で動きます。担当する片手の4鍵内に収めています。
- 元音声のアタックが安定して続く区間を選び、新しい等間隔の時刻は挿入していません。シンコペーションや休符を無理に埋めません。

HARDは35曲すべて、NORMALは25曲にあり、合計225区間（移動66区間）です。EASYは片手のメロディと左右交代を中心にしています。初音ミクの消失HARDでは31.615秒から24打のトリル、96.238秒から20打の移動トリルがあります。

## 検証と音

全95,730ノーツをv18と比較し、79,167ノーツのレーンを変更しました。ノーツ数・時刻・休符・ロングの長さ・同時押し・FLOATは維持しています。左右を入れ替えてもピアノの音程や声部が入れ替わらないよう、元の声部の順序を保持しています。全ノーツで従来の音程と発音情報が一致しました。

`npm test` は85件成功。全105譜面の100万点入力再生、長押しとの重複、全打鍵の発音、主旋律と伴奏の手、交代、トリルの交互打ちを検証しています。音声由来の既存ノーツを再配置したもので、全曲を耳で聴きながら通し演奏した検証ではありません。

ブラウザとオンライン採点は `piano8-hands-v19` を使用します。旧スコアは削除せず、譜面バージョンごとに保存します。
