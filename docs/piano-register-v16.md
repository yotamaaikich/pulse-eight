# ピアノの低音域修正 v16

v15の全音源混合からの推定は、歌や高い楽器の間にあるベース寄りの音も鍵盤音として選んでいました。低域を優先する重み付け、MIDI 48（C3）までの候補、弱い音域連続性の制約により、前後から2オクターブ以上低く落ちる音が混ざっていました。旋律と伴奏の取り違え、低い候補のオクターブ選択が、急に低い鍵盤音が入る原因でした。

## 変更範囲

- 全35曲の同じ公式音声を再解析。対象は低音域（C4未満）を選んでいた主音19,848箇所です。
- 既存のモニタリング歌声・安定歌声と、中高音域の主音26,996箇所は変更していません。
- 低い伴奏の音高クラスに中音域の倍音支持がある場合は、そのクラスを保ってオクターブを調整します（8,871箇所）。根拠の弱い箇所は、元音声の中音域の倍音、局所的な音の組合せ、前後の旋律との連続性から再選択しました（10,977箇所）。低音の一律な音量カットや、全音を同じ音程にする修正ではありません。
- 同時押しの低い別音も主音から1オクターブ以内へ移動。主音の再選択で以前の和音関係が合わなくなった場合は同じ音高を重ねます。この整合のため、中高音域の別音も131箇所変更しています。
- 今後の音程データでも、推定伴奏がC4未満のまま発音されないよう通常ノーツ・空打ちの両方に音域の下限を設けました。既存の歌声音程と任意に読み込んだ旋律の意図された低音は維持します。

6つの録音ピアノMP3、内蔵ピアノ、エンベロープ、コンプレッサー、音量設定はv15から変更していません。ノーツ時刻・長押し・同時押し・FLOATの配置と採点も同じです。スコアの譜面バージョンは `piano8-arrangement-v12` のままです。

## 解析と確認

音源のSHA256と曲別件数は [song-piano-v16.json](song-piano-v16.json)、全105譜面の発音割り当ては [piano-register-audit-v16.json](piano-register-audit-v16.json) に記録しています。

音声アタック46,844箇所の時刻・由来は保持。混合音のスペクトルを時間・周波数方向で分離し、局所コントラストで低域の音量の支配を抑え、C4以上の基本音と倍音の候補を再評価しました。局所の中高音・歌声を基準にし、曖昧な候補では急落を避けます。実音に支持される既存の音高クラスは保つため、単純に最も高い候補を選ぶ処理ではありません。

700ms未満の間に19半音以上動く主音の箇所は、3,623から382へ減少しました。全105譜面ではC4未満の推定伴奏が41,340ノーツからゼロとなり、既存の歌声の低音は維持されています。全95,730ノーツにピアノの音高があり、発音の欠落はありません。

80件のテストで、低域推定の再混入防止、既存歌声の保持、全105譜面の入力・ロング・FLOAT、時刻と採点の不変を検査しています。[ブラウザ出力](browser-piano-register-v16.json) は実際の録音ピアノのWeb Audioグラフを出力した比較です。低音が混ざっていた5事例では200Hz以下の成分のRMSが修正前の約13〜38%になり、維持した中高音2事例は出力波形SHA256が一致しました。

これは音声解析・発音経路・出力波形による検査です。耳で全曲を通し演奏した結果ではなく、全ての推定音が正確な主旋律だとはしていません。元音声に複数の楽器が重なるため、伴奏への追従や半音・オクターブの推定違いが残る可能性があります。原曲音声・歌詞本文・第三者の楽譜/MIDIは配信していません。
